# Contributing

Please reproduce the isolated tests and read the known gaps before proposing changes. Keep task-routing changes separate from native authorization or global configuration changes. Never attach real tokens, configuration files or unredacted transcripts. Use synthetic inputs in reproductions. A local test is not live inference, delivered-message proof, measured savings or a security audit.

For upstream OpenClaw work, follow that project's current contribution guide and discuss architecture before opening a non-trivial PR. This repository cannot grant upstream approval.
